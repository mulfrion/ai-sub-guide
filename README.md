# AI 订阅指南（ai-sub-guide）

关于 ChatGPT、Claude、Gemini 订阅的价格构成、额度规则与代充资料的静态内容站，发布在 GitHub Pages：

https://mulfrion.github.io/ai-sub-guide/

## 内容

- `index.html` — 首页与文章列表
- `articles/` — 6 篇说明文章（价格、Session、套餐对比、Codex 额度）
- `sitemap.xml`、`robots.txt` — 搜索引擎收录
- `assets/style.css` — 全站样式

## 维护说明

- 内容按官方说明与实际流程整理，套餐价格以主站商品页为准。
- 主站：[getvip.pro](https://getvip.pro)；代充安全说明：[getvip.pro/safety](https://getvip.pro/safety)
- 本站为独立内容站，不处理订单，售后以主站订单页为准。

python3 -m http.server 8090
